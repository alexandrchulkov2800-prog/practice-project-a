# Журнал практики

## Запись 1. Подготовка репозитория

**Этап:** Начало проектной практики

В начале работы был создан личный репозиторий на GitHub на основе предоставленного шаблона. Репозиторий был склонирован на локальный компьютер с помощью GitHub Desktop.

Была проверена структура репозитория и изучено назначение основных папок: `docs`, `reports`, `site` и `task`.

Также был выполнен первый commit с основной информацией о практике.

## Запись 2. Подготовка документации проекта

**Этап:** Документация основного проекта

Была подготовлена документация по проекту «Создание единой информационной системы для обработки заявлений и обращений студентов».

В документации описаны проблема проекта, его цель, основные пользователи, функции системы, требования и ожидаемый результат.

Подготовленная документация была добавлена в репозиторий в формате Markdown.

## Запись 3. Настройка работы с Git

**Этап:** Работа с системой контроля версий

В процессе выполнения практики была освоена базовая работа с GitHub Desktop.

Были выполнены операции создания commit и отправки изменений в удалённый репозиторий GitHub с помощью `Push origin`.

В результате изменения документации были сохранены в истории репозитория отдельными commit-ами.

## Результат текущего этапа

На текущем этапе создан и настроен личный репозиторий проекта, подготовлена основная документация и освоена базовая работа с Git и GitHub Desktop.

Следующим этапом является разработка статического сайта проекта и дальнейшее выполнение вариативной части практики.
