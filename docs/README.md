# Документация проекта

## Название проекта

**Создание единой информационной системы для обработки заявлений и обращений студентов**

## Описание проблемы

В учебном заведении обработка заявлений и обращений студентов может выполняться с использованием электронной почты, бумажных документов и личного обращения в подразделения.

Такой подход может приводить к задержкам обработки заявлений, появлению дублирующихся обращений, сложностям с контролем сроков и дополнительной нагрузке на сотрудников.

## Цель проекта

Создать единую информационную систему для подачи, обработки и контроля заявлений и обращений студентов.

Система должна обеспечить возможность подачи обращения в электронном виде, отслеживания его статуса и получения уведомлений об изменениях.

## Основные пользователи

* **Студенты** — создают заявления и обращения, прикладывают документы и отслеживают статус.
* **Сотрудники учебного заведения** — рассматривают обращения, назначают ответственных и контролируют сроки обработки.
* **Администраторы** — управляют системой и получают сводную информацию о работе с обращениями.

## Основные функции

### Для студентов

* создание заявления или обращения;
* прикрепление необходимых документов;
* просмотр статуса обращения;
* получение уведомлений;
* просмотр истории обращений.

### Для сотрудников

* просмотр поступивших обращений;
* назначение ответственного сотрудника;
* изменение статуса обращения;
* контроль сроков выполнения;
* формирование отчётности.

### Для администраторов

* управление пользователями;
* настройка системы;
* просмотр статистики;
* контроль работы системы.

## Основные требования

* работа системы в режиме 24/7;
* отказ от бумажных заявлений;
* возможность дальнейшего расширения системы;
* возможность подключения новых подразделений;
* контроль сроков обработки обращений;
* хранение истории обращений.

## Ожидаемый результат

В результате проекта должна быть разработана концепция единой информационной системы, позволяющей перевести работу с заявлениями и обращениями студентов в электронный формат и упростить контроль их обработки.

## Связь с проектной практикой

Проект используется как основа для выполнения проектной (учебной) практики.

В рамках вариативной части практики отдельно выполняется практическая реализация технологии **C++ Space Invaders from Scratch**.
