Документация и материалы проекта

Документация Space Invaders

Подробное описание исследования и практической реализации игры: технологии, структура проекта, игровой цикл, состояния игры, управление, тестирование и дополнительные изменения.

Открыть документацию

Исходный код игры

Основная логика игры находится в файле src/main.cpp. В нём реализованы игровой цикл, управление, движение противников, стрельба, столкновения, очки, жизни и состояния игры.

Файл находится в каталоге проекта space-invaders/src/.

CMake

Для сборки проекта используется CMake. Конфигурация проекта находится в файле space-invaders/CMakeLists.txt.

CMake отвечает за настройку сборки и подключение библиотеки raylib.

Используемые технологии

C++17

Основной язык программирования, на котором реализована игровая логика проекта.

raylib

Графическая библиотека, использованная для создания окна, отрисовки игровых объектов, обработки клавиатуры и других элементов игрового приложения.

CMake

Инструмент автоматизации сборки проекта.

Visual Studio 2022

Среда разработки и компилятор C++, использованные для сборки и запуска приложения в Windows.

Исследовательские материалы

Space Invaders from Scratch

В качестве исследовательского материала изучался пример создания Space Invaders на C++ с использованием OpenGL, GLFW и GLEW.

Материал использовался для изучения общей структуры игровой программы, игрового цикла и основных этапов разработки.

Практическая реализация в данном проекте выполнена самостоятельно с использованием raylib.

Материалы основного проекта

Информационная система обработки заявлений студентов

Основной проект проектной деятельности посвящён созданию концепции единой информационной системы для обработки заявлений и обращений студентов.

Материалы проекта включают описание проблемы, цели, задач, пользователей, требований и ожидаемого результата.

Основное описание также представлено в каталоге docs/ репозитория.

Инструменты разработки

Git и GitHub

Git использовался для контроля версий проекта, фиксации изменений и ведения истории разработки. GitHub использовался для хранения удалённого репозитория проекта.

GitHub Desktop

GitHub Desktop использовался для выполнения основных операций с репозиторием: просмотра изменений, создания коммитов и отправки изменений на GitHub.

Все основные материалы практической части находятся непосредственно в репозитории проекта. Это позволяет сохранить исходный код, документацию и графические материалы вместе.
