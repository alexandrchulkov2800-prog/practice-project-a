Журнал практики

Запись 1. Подготовка репозитория

Этап: начало проектной практики

Был создан личный репозиторий на GitHub на основе предоставленного репозитория практики. Репозиторий был склонирован на локальный компьютер с помощью GitHub Desktop.

Была проверена структура репозитория и изучено назначение основных папок: docs, reports, site и task.

Запись 2. Документация основного проекта

Этап: подготовка материалов проектной деятельности

Была подготовлена документация по основному проекту «Создание единой информационной системы для обработки заявлений и обращений студентов».

В документации описаны проблема проекта, цель, основные задачи, пользователи, функции системы, требования и ожидаемый результат.

Запись 3. Работа с Git и GitHub

Этап: система контроля версий

Была освоена базовая работа с GitHub Desktop: просмотр изменений, создание commit и отправка изменений в удалённый репозиторий GitHub.

Основные изменения проекта фиксировались отдельными commit-ами, что позволило сохранить историю разработки.

Запись 4. Разработка Space Invaders

Этап: выполнение вариативной части практики

Для вариативной части практики был выбран вариант разработки игры Space Invaders на языке C++.

Была создана рабочая версия игры с использованием C++, raylib и CMake. Реализованы игровое окно, управление игроком, движение противников, стрельба и проверка столкновений.

Дополнительно были реализованы очки, жизни игрока, экран Game Over и система последовательных волн противников с увеличением скорости.

Запись 5. Документация Space Invaders

Этап: техническая документация

После разработки игры была подготовлена подробная Markdown-документация по практической части.

В документе описаны использованные технологии, структура проекта, игровой цикл, состояния игры, управление, параметры, процесс сборки и запуска, тестирование и внесённые изменения.

Для наглядного представления проекта были подготовлены SVG-схемы архитектуры, игрового цикла, состояний игры и системы волн, а также добавлены скриншоты работающей игры.

Запись 6. Создание статического сайта

Этап: оформление результатов практики

Был создан статический сайт проектной практики с использованием HTML и CSS.

На сайте подготовлены отдельные страницы с информацией о проектах, участнике, журнале практики, ресурсах и медиа-материалах.

На страницы сайта добавлены описания основного проекта и Space Invaders, скриншоты игры и технические SVG-схемы.

Текущий результат

Этап: подготовка материалов к сдаче

Подготовлены основные материалы проектной практики: документация основного проекта, практическая реализация Space Invaders, техническая документация и статический сайт.

Следующие этапы связаны с финальной проверкой сайта, подготовкой видеопрезентации и оформлением итогового отчёта по практике.
