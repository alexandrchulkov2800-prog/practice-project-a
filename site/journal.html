Журнал практики

Запись 1. Подготовка репозитория

Этап: начало проектной практики

Был создан личный репозиторий на GitHub на основе предоставленного шаблона. Репозиторий был склонирован на локальный компьютер с помощью GitHub Desktop.

Была проверена структура репозитория и изучено назначение основных папок: docs, reports, site и task.

Запись 2. Подготовка документации проекта

Этап: документация основного проекта

Была подготовлена документация по проекту «Создание единой информационной системы для обработки заявлений и обращений студентов».

В документации описаны проблема проекта, его цель, основные пользователи, функции системы, требования и ожидаемый результат.

Запись 3. Работа с Git и GitHub

Этап: система контроля версий

Была освоена базовая работа с GitHub Desktop. Выполнены операции создания commit и отправки изменений в удалённый репозиторий GitHub.

Документация проекта была сохранена в истории репозитория отдельными commit-ами.

Текущий результат

Создан и настроен репозиторий проекта, подготовлена основная документация и начата разработка статического сайта практики.

Следующие этапы связаны с наполнением сайта, добавлением материалов проекта и выполнением вариативной части практики.
